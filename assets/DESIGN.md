## 5. 验收与使用原则

| 验收层级 | 必须核对 | 结论边界 |
| --- | --- | --- |
| 文档结构 | 九个 YAML 顶层字段、字段类型、五章顺序、无占位残留 / 对象序列化错误，正文与 `omitted` 一致 | 格式通过不代表参数充分 |
| 证据与素材 | 参数可追溯、声明 / 计算 / 量测可区分，真实素材清单、路径、字节、哈希与解码 / 加载 | 素材齐备不代表页面还原 |
| 布局与视觉 | 桌面 / 平板 / 手机同视口、DPR、字体加载和状态；逐区块文字、几何、裁切、层级，首中末项与滚动位置 | 列明实测项、误差与跳过项；几何通过不等于全图像素一致 |
| 交互与动效 | 状态矩阵、主要路径、键盘焦点、重置 / 返回、窄屏溢出、减少动态效果、实际动画 / 媒体行为 | 参数一致不等于逐帧曲线或听感一致 |
| 独立复现（需要时） | 冻结文档和素材，由未看原站的实现者完成；评估方再对照原站，记录差异 | 只对实际验收的页面、视口、状态和素材作结论 |

- 截图和几何量测采用同一坐标基准，不缩放截图后冒充原始测量。动态画面先对齐时间 / 相位；不同播放时刻的静态差异不能直接判为动效失败。音频等价需另有同设备听感或输出信号对照证据。
- 随机或持续模拟场景记录<随机性、墙钟/模拟时钟、实际渲染条件、是否使用可复现测试配置>。区分正常运行与测试改造、状态一致与逐帧等价；缺乏相位/随机控制时，完整差分仅作描述，逐帧结论保留未验证。/ Separate ordinary operation, deterministic experiments, state agreement and frame equivalence.
- 报告区分通过、失败、未验证和不适用；列明实际比较数、跳过数、误差与范围，不把局部项通过率称为“复刻百分比”。未完成同视口对照、主要交互和素材加载时，不声称完整复刻。
- 未定义项在对应正文说明并列入 `omitted`，写清缺什么、影响什么、需要何种证据；不得以空列表掩盖未测内容。日期、采集过程与验证记录另存；冻结后的实验输入保留原状，后续验收结果写入报告，不追改输入冒充事前已知。
